 13. SVG TREND LINE CHARTS  (time-series data)
────────────────────────────────────────────────────────────────────────────────

 Attributes     : viewBox="0 0 800 80", preserveAspectRatio="none"
                  width 100%, height 80px (CSS), display block

 Line           : <path> stroke 2px, no fill, stroke-linejoin round

                  value <text> at first point, midpoint, last point
                  font-size 9, text-anchor middle, fill #333

 Color by metric:
   Memory usage    → #0057a8
   CPU percentage  → #00b4e6

 15. GLOSSARY TOOLTIPS
────────────────────────────────────────────────────────────────────────────────

 Trigger span   : <span class="term" data-term="KEY">text</span>
   Style        : border-bottom 1px dashed #0057a8, color #0057a8, cursor help

 Tooltip div    : id="tooltip", class="tooltip-box"
   position     : fixed
   background   : #003366
   color        : #ffffff
   padding      : 10px 14px
   border-radius: 8px
   font-size    : 0.78rem
   max-width    : 280px
   z-index      : 9999
   box-shadow   : 0 4px 12px rgba(0,0,0,.4)
   pointer-events: none
   display      : none (shown on hover via JS)

 Tooltip <strong> (term title): color #a8d0f0

 JavaScript behavior:
   mousemove → set tooltip innerHTML, display:block,
               position at e.clientX+14 (clamped to window.innerWidth-300),
               e.clientY-10 (clamped to window.innerHeight-80)
   mouseleave → display:none

────────────────────────────────────────────────────────────────────────────────
 18. TECHNICAL RULES
────────────────────────────────────────────────────────────────────────────────

 - Single .html file output — no external files, no folders
 - Zero external dependencies — no CDN links, no Google Fonts, no remote images
 - All CSS inside <style> block in <head>
 - All JavaScript inside <script> block immediately before </body>
 - No HTML comments in the output
 - No text nodes outside of HTML tags
 - SVG logo must be inline — never use <img> tags
 - box-sizing: border-box on all elements (universal selector)
