📋 Overview

The SAP HANA SQL Console is a lightweight browser-based SQL workbench for SAP HANA databases. It runs entirely as a local Python process — no installation of a full SAP HANA Studio or SAP HANA Cockpit is required. Open a browser, connect, and query.


PropertyValue
Scripthana_tui_web_8.py
PlatformWindows 10 / 11 (64-bit) — hdbcli native library is Windows-only
LanguagePython 3.10 or later (stdlib only — no Flask, no Django)
UIBrowser-based single-page app served from http://127.0.0.1:5000
HANA connectionhdbcli (SAP HANA Client Python library) — bundled in lib\
Default port5000 (localhost only — not exposed on the network)
External dependenciesNone — all JS/CSS embedded; Chart.js served from local lib\

Self-contained design

The entire application — HTTP server, UI, API endpoints — is a single .py file. The HTML, CSS, and JavaScript are embedded directly in the Python source as the HTML_PAGE string. No internet connection is required after installation.

✨ Features

🔌 HANA Connection

Connect to any SAP HANA instance (on-prem or cloud) using hostname, port, username, and password. Connection state shown in the header with a live indicator dot.

✏️ SQL Editor

Multi-line SQL editor with Execute (F5) and Clear buttons. Supports any SQL statement. Row limit configurable (default 500, or unlimited).

📊 Results Grid

Tabular result display with column headers. Exports results as CSV. Shows execution time and row count. Warns when results are capped at the row limit.

📁 Mini-Checks Library

Sidebar with 35+ pre-built SAP HANA diagnostic SQL scripts (SAP Note mini-checks). Filter by name, click to load into the editor, execute directly.

📦 Basic Bundle

One-click execution of the full mini-check script bundle. Runs all scripts against the connected HANA, consolidates results into a single downloadable .txt file with a progress bar.

🗂️ Output Manager

Lists all saved output files. Download individual files, consolidate multiple files into one report, or clear the output folder.

📈 Charts

Embedded Chart.js for visual data representation. Loaded from the local lib\ folder — no internet required.

🔒 Local-only access

Server binds to 127.0.0.1 only. The web interface is accessible only from the local machine, not from other hosts on the network.

📁 File Structure

Must copy all items marked Required

The app is fully self-contained in its folder. All paths are relative to the script's location — no hardcoded absolute paths. Copy the entire folder to deploy.


hana_tool\  ← copy this entire folder to the new machine
│
├── hana_tui_web_8.py  ← the application (REQUIRED)
│
├── lib\  ← bundled libraries (REQUIRED — do not rename)
│ ├── hdbcli\  ← HANA Python client package
│ ├── pyhdbcli.pyd  ← HANA native Windows extension (Win64 only)
│ └── chart.umd.min.js  ← Chart.js served at /static/chart.umd.min.js
│
├── mini_checks\  ← SQL script files (REQUIRED for scripts / bundle features)
│ ├── HANA_Backups_BackupRuns_2.00.070+.txt
│ ├── HANA_Configuration_Overview_2.00.040+.txt
│ └── ... 35+ script files ...
│
├── output\  ← generated CSV/TXT files (auto-created on first save)
│
└── packages\  ← offline .whl files for reference (not needed at runtime)

Critical: keep lib\ and mini_checks\ together with the script

Both directories must be in the same folder as hana_tui_web_8.py. If you move just the .py file without the supporting folders, hdbcli will fail to load and the mini-check library will be empty.

🛠 Manual Installation Steps

Step by step
  1. Install Python 3.10 or later (Windows 64-bit installer) Download from python.org.
    During setup: ✅ Add Python to PATH  |  ✅ Install launcher for all users
    Verify: open Command Prompt → python --version
  2. Copy the entire hana_tool\ folder to the new machine Copy from the source (shared drive, USB, OneDrive) to any local path, for example: 
    C:\HANA_Tools\hana_tool\
    The folder must contain: hana_tui_web_8.py, lib\, mini_checks\.
  3. Verify hdbcli loads correctly Open Command Prompt, navigate to the folder, and test: 
    cd C:\HANA_Tools\hana_tool
python -c "from hdbcli import dbapi; print('hdbcli OK')"
    Expected output: hdbcli OK
    If you see an ImportError, check that lib\pyhdbcli.pyd exists and Python is 64-bit 3.10+.
  4. Create a run launcher (optional but recommended) Create a file run.bat in the hana_tool\ folder: 
    @echo off
cd /d "%~dp0"
python hana_tui_web_8.py
pause
    Double-click it to start the console. The pause keeps the window open if there is an error.
  5. Create a desktop shortcut (optional) Right-click the Desktop → New → Shortcut.
    Target: C:\HANA_Tools\hana_tool\run.bat
    Name: HANA SQL Console
  6. Run the app Double-click run.bat or the desktop shortcut. The browser opens automatically at http://127.0.0.1:5000. The console window must stay open while you use the app — closing it stops the server.

🚀 Automated Installer

Recommended

The file install_hana_sql_console.bat (in the same folder as this guide) automates the setup on a new machine.

What the installer does

  • Checks Python is installed and is 64-bit 3.10+
  • Prompts for the target installation directory
  • Copies the entire hana_tool\ folder to the chosen location
  • Verifies hdbcli loads correctly after copy
  • Creates run.bat launcher in the install directory
  • Creates a desktop shortcut
  • Optionally checks that port 5000 is free

Usage

REM Copy the hana_tool\ folder to the new machine, then run:
install_hana_sql_console.bat

Source folder requirement

Run the installer from inside the hana_tool\ folder (or ensure lib\ and mini_checks\ are present next to the .bat file). The installer copies everything from its own directory to the target.

▶ Running the App

Usage

Start the server

The app is a local HTTP server. You must keep the console window (or Command Prompt) open while using it.

# Option A — double-click run.bat (if created by installer)

# Option B — command line
cd C:\HANA_Tools\hana_tool
python hana_tui_web_8.py

# Expected output:
HANA SQL Console v6.0 running at http://127.0.0.1:5000  (Ctrl+C to stop)

The browser opens automatically at http://127.0.0.1:5000. If it does not, open it manually.

Stop the server

Press Ctrl+C in the console window, or close the window.

Multiple instances

Do not run two instances of the app at the same time — the second one will fail to bind to port 5000. Stop the first instance before starting a new one.

🔌 Connecting to SAP HANA

Required before any query

After opening the browser, the connection panel appears at the top. Fill in the HANA connection details and click Connect.

FieldDefaultDescription
HostemptyHostname or IP address of the SAP HANA server (e.g. vhbozehpdb01 or 10.x.x.x)
Port30241HANA SQL port. Common values: 30013 (MDC system DB), 30015, 30041 (tenant ports). For non-default instances, port = 3<NN>13 where NN = instance number.
DatabaseHP4Tenant database name (for MDC). For SystemDB connections use SYSTEMDB.
UseremptyHANA database user (e.g. SYSTEM or a monitoring user)
PasswordemptyHANA database user password

Common port numbers

  • 3<NN>13 — MDC System DB (NN = instance number, e.g. 30013 for instance 00)
  • 3<NN>15 — First tenant (default MDC tenant port)
  • 3<NN>41, 3<NN>42 — Additional tenants
  • Custom ports are visible in SELECT * FROM SYS.M_SERVICES on the HANA system

A green dot in the header confirms a successful connection. The host, port, database, and user are displayed.

📖 Usage Guide

Features

SQL Editor

Type or paste any SQL statement into the editor. Press F5 or click Execute to run.

  • Results are shown as a table with column headers
  • Execution time and row count are displayed below the results
  • Default row limit: 500. Set to 0 for unlimited (use carefully on large result sets)
  • A warning banner appears when results are capped at the row limit
  • Click Export CSV to save the current result set as a CSV file in the output\ folder
  • Statements starting with -- (SQL comments) are automatically stripped before execution

Mini-Checks Library

Click the Scripts toggle button to open the sidebar. All .txt / .sql files in the mini_checks\ folder appear here.

  • Use the filter box to search by script name
  • Click a script to load it into the SQL editor
  • Click Execute (or F5) to run it
  • Results can be exported as CSV individually

Basic Bundle (Batch Execution)

The Basic Bundle runs all 35+ mini-check scripts in sequence against the connected HANA database and consolidates the results into a single downloadable .txt file.

  1. Connect to a HANA database first
  2. Click Run Basic Bundle
  3. A progress bar shows script-by-script progress
  4. When complete, click the download link to get the consolidated output file
  5. The file is named Consolidated_minichecks_basic_bundle_YYYYMMDD.txt
  6. Scripts that fail (SQL error or missing file) are reported as "skipped" — they do not abort the bundle

Basic Bundle output format

The output file contains all results in CSV format, separated by ==== headers identifying each script. This file can be used directly as input to the HANA Analysis Report Generator (hana_analysis_app_v6.01.py).

Output Manager

The Outputs panel lists all saved files in the output\ folder.

  • Click a filename to download it
  • Select multiple files and click Consolidate to merge them into one report
  • Click Clear All to delete all output files

🔍 Troubleshooting

Help
SymptomLikely CauseFix
ImportError: No module named 'hdbcli' lib\ folder missing or pyhdbcli.pyd not found Ensure lib\ is in the same folder as the .py file and contains pyhdbcli.pyd
OSError: [WinError 193] on import Python is 32-bit but pyhdbcli.pyd is 64-bit Install the 64-bit Python distribution
OSError: [Errno 98] Address already in use Port 5000 is already used by another process Stop the other app, or change the port: edit line 3140: port = 5001
Browser does not open automatically webbrowser module cannot find a browser Manually navigate to http://127.0.0.1:5000
Connection error: Cannot connect to host Firewall, wrong host/port, or VPN not connected Verify network connectivity: ping <host>; check HANA port with: telnet <host> <port>; connect VPN if needed
Connection error: authentication failed Wrong username or password Verify credentials directly in SAP HANA Cockpit or via HANA Studio
Scripts sidebar is empty mini_checks\ folder missing or empty Ensure mini_checks\ is in the same directory as the script and contains .txt files
Basic Bundle finishes with many "skipped" SQL errors on scripts not supported by this HANA version Normal for older HANA versions — scripts with 2.00.070+ suffix require HANA 2.0 SPS07+. Check the skipped list for details.
App freezes / stops responding A long-running SQL query is blocking Stop the server (Ctrl+C), restart, and use a more restrictive query or shorter row limit
Page loads but shows 404 for /static/chart.umd.min.js lib\chart.umd.min.js missing Charts will not display. Copy the file to lib\. The rest of the app works without it.
