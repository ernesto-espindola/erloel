📋 Overview

What the installer does in one minute.

The installer sets up the SAP HANA Mini Checks Console v2.0 — a browser-based SQL execution environment for SAP HANA. It runs entirely on your workstation; no server or cloud connection is needed beyond network access to the target HANA system.


The installer package (install_minichecks_console_full.zip) contains:


File in ZIPPurpose
install_minichecks_console.batThe installer script (5 automated steps)
minichecks_console_V2.0.pyThe main application (~3 000 lines, Python)
SQLStatements.zip421 SAP HANA SQL mini-check scripts (from SAP Note SQLStatements collection)

✅
The installer works from a completely fresh Windows machine — it detects and auto-installs the hdbcli Python driver via pip if not already present. Only Python 3.10+ 64-bit must be installed beforehand.

✅ Prerequisites

What must be in place before running the installer.
RequirementMinimumStatusWhere to get it
Python 3.10+, 64-bit, with tkinter Required python.org/downloads — download the Windows 64-bit installer. During setup, check "Add Python to PATH".
hdbcli Any recent version Auto-installed The installer detects if it is already present. If not, it runs pip install hdbcli automatically (requires internet access to pypi.org).
Chart.js chart.umd.min.js Auto-downloaded Downloaded from cdn.jsdelivr.net during install. If blocked by corporate proxy, the Chart tab will be unavailable — the rest of the app works normally.
Network to HANA Port 30241 (or custom) Required at runtime Your workstation must be able to reach the HANA host on the SQL port. VPN may be needed.
Port 5000 free localhost:5000 Required at runtime The app runs a local HTTP server on port 5000. The installer checks this and warns if occupied.

Verify Python before running the installer

Open PowerShell or Command Prompt and run:

python --version
python -c "import struct; print('64-bit' if struct.calcsize('P')*8==64 else '32-bit — WRONG')"

Both commands must succeed and Python must be 64-bit. If python is not found, install Python first.

📂 Step 1 — Extract the ZIP

Unzip all files before running the installer.
  1. Locate the downloaded ZIP

    Open File Explorer and navigate to your Downloads folder. Find install_minichecks_console_full.zip.

  2. Right-click → Extract All…

    Right-click the ZIP file and choose Extract All…. Use the suggested destination (a subfolder in Downloads) or choose any folder. Click Extract.

  3. Confirm the extracted files

    After extraction you should see three files in the folder:

    Downloads\install_minichecks_console_full\
    ├── install_minichecks_console.bat ← the installer
    ├── minichecks_console_V2.0.py ← main application
    └── SQLStatements.zip ← 421 SQL scripts
⚠️
Do NOT run the .bat directly from inside the ZIP (double-clicking without extracting). The installer reads files from its own folder — they must all be extracted first.

▶️ Step 2 — Run the Installer

How to launch install_minichecks_console.bat correctly.
  1. Open the extracted folder in File Explorer

    Navigate to the folder where you extracted the ZIP.

  2. Right-click install_minichecks_console.bat → Run as administrator

    Running as administrator is recommended to allow creating directories and desktop shortcuts without permission errors. If you choose not to run as admin, enter a path inside your user profile when prompted (e.g. C:\Users\YourName\Downloads\minichecks_console — which is the default).

  3. A Command Prompt window opens and the installer begins

    The installer runs 5 steps automatically. The only interaction required is entering the installation path at step 3 — press Enter to accept the default.

💡
If you see "This app has been blocked by your system administrator", right-click the .bat → Properties → check Unblock at the bottom → OK. Then run again.
ℹ️
If you are running from PowerShell, type .\install_minichecks_console.bat (with the .\ prefix). Do NOT just type the filename — PowerShell requires it.

STEP 2 / 5

Setting up hdbcli

The installer checks for the SAP HANA Python client driver (hdbcli) using three detection methods in order:

Bundled lib\pyhdbcli.pyd found alongside installerUses the pre-bundled files (fastest, offline)No
hdbcli already pip-installed in PythonDetects it and skips installNo
Neither foundRuns pip install hdbcli from PyPIYes

After hdbcli is set up, the installer also attempts to download Chart.js from the CDN. If the CDN is unreachable (corporate proxy blocks it), Chart.js is skipped and the Chart tab in the app will be unavailable — everything else works normally.

🚀 Launching the App

How to start the Mini Checks Console after installation.
  1. Double-click "HANA Mini Checks v2" on the Desktop

    Or run run_minichecks.bat from the install folder. A black console window opens — keep it open while using the app.

  2. The browser opens automatically at http://127.0.0.1:5000

    If the browser does not open automatically, open it manually and navigate to http://127.0.0.1:5000.

  3. Enter the HANA connection details

    Fill in: Host (HANA hostname or IP), Port (default 30241 for single-tenant or 3<NN>15 for tenant), Database, User, Password. Click Connect.

  4. A green dot confirms a live HANA connection

    Write SQL in the editor and press F5 or click Run to execute. Use the Mini Checks sidebar to browse and load the 421 diagnostic scripts from mini_checks\.

  5. To stop the server

    Press Ctrl+C in the black console window, or simply close it.

⚠️
Keep the console window open while using the app. Closing it stops the local HTTP server and the browser interface will stop responding.

🔧 Troubleshooting

Common errors and how to resolve them.

"requires was unexpected at this time" when running the .bat

⚠️
The file has LF (Unix) line endings. Always use the .zip package — extracting it preserves CRLF line endings. If you have the bare .bat file, run in PowerShell:

(Get-Content "install_minichecks_console.bat") | Set-Content "install_minichecks_console.bat"

"This app has been blocked by your system administrator"

⚠️
Right-click the .bat file → Properties → check Unblock at the bottom → OK. Then run again.

"Cannot create directory" error at step 3

⚠️
The path requires Administrator rights (e.g. C:\HANA_Tools\). Either run the installer as Administrator, or enter a path inside your user profile when prompted:

C:\Users\YourName\Downloads\minichecks_console (the default) does not require admin.

hdbcli pip install fails

⚠️
  • Check internet connectivity: ping pypi.org
  • If behind a corporate proxy: pip install hdbcli --proxy http://proxy:port
  • Alternatively, obtain the hdbcli-*.whl wheel from SAP and run pip install hdbcli-*.whl

Browser does not open / "Address not reachable"

ℹ️
  • Check the console window — if it shows an error, port 5000 may be in use
  • Find what is using port 5000: netstat -ano | findstr :5000
  • Stop that process, or change the port in the last lines of minichecks_console_V2.0.py
  • Navigate manually to http://127.0.0.1:5000 if the browser did not open automatically

HANA connection fails (red dot)

ℹ️
  • Verify host name/IP and port number — for SystemDB use 3<NN>13, for tenant use 3<NN>15
  • Confirm your workstation can reach the HANA host (VPN may be required)
  • Ensure the HANA user has the PUBLIC role and sufficient permissions for the queries you intend to run

Chart tab not working

ℹ️
Chart.js was not downloaded (CDN blocked). To enable it manually:

Download chart.umd.min.js on a machine with internet access from:
https://cdn.jsdelivr.net/npm/chart.js/dist/chart.umd.min.js

Copy the file to: [install folder]\lib\chart.umd.min.js and restart the app.

mini_checks\ scripts not appearing in the sidebar

ℹ️
Verify the scripts were extracted: open [install folder]\mini_checks\ in Explorer — you should see ~421 .txt files. If empty, extract SQLStatements.zip manually into that folder.
