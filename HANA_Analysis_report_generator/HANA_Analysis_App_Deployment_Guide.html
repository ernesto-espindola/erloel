📋 Overview

The HANA Analysis Report Generator is a Windows desktop application (Python / Tkinter GUI) that reads a SAP HANA Health Check output file and automatically generates a formatted HTML analysis report — and optionally a PowerPoint presentation — using the Claude AI API (via SAP's internal AI proxy).


FeatureDetails
PlatformWindows 10 / 11 (64-bit)
LanguagePython 3.10 or later
GUI frameworkTkinter (included with Python on Windows)
AI backendClaude (Anthropic) via SAP internal AI proxy
OutputInteractive HTML report + optional PPTX
Source filehana_analysis_app_v6.01.py
Prompt templateHANA_HealthCheck_Prompt_Template.md

How it works

The user selects a HANA Health Check .txt output file via the GUI. The app reads the prompt template, injects the health check text, and sends the full prompt to Claude via the SAP AI proxy using streaming. The generated HTML is post-processed (CSS injection, SAP logo, footer) and saved to the Results/ folder, then opened automatically in Microsoft Edge.

│

│
├── HANA Health Check Reports\  ← place input .txt files here

🔧 Configuration

Required

There are two configuration points that must be adapted when moving to a new machine.

1 — Hardcoded paths inside the .py file

Open hana_analysis_app_v6.01.py and edit the four constants at the top of the file (lines 35–41):

# ── Config — EDIT THESE FOR YOUR MACHINE ─────────────────────────────
WORKING_DIR   = Path(r"C:\HANA_Analysis_App")            # <-- your working folder
TEMPLATE_FILE = WORKING_DIR / "HANA_HealthCheck_Prompt_Template.md"
RELEASE_FILE  = WORKING_DIR / "HANA_latest_release.txt"
OUTPUT_DIR    = WORKING_DIR / "Results"
LOGO_PATH     = WORKING_DIR / "SAP_LOGO.png"
EDGE_PATH     = r"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe"
SETTINGS_FILE = Path(r"C:\Users\YOUR_USER\.claude\settings.json")   # <-- your user folder

Important — SETTINGS_FILE

This path points to the Claude Code settings.json file where the AI proxy token and endpoint URL are read from. If Claude Code is not installed on the target machine, create the file manually (see below). The folder .claude must exist under the user's home directory.

2 — settings.json (AI proxy credentials)

The app reads the following keys from %USERPROFILE%\.claude\settings.json:

{
  "env": {
    "ANTHROPIC_BASE_URL": "http://localhost:6655/anthropic/",   // SAP AI proxy endpoint
    "ANTHROPIC_AUTH_TOKEN": "your-sap-ai-token-here",               // SAP AI token (UUID format)
    "ANTHROPIC_MODEL": "claude-sonnet-latest"                      // model to use
  }
}

Token format

The ANTHROPIC_AUTH_TOKEN is a SAP-internal UUID-format token (e.g. xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx), NOT a standard Anthropic API key. Obtain it from your team lead or the SAP ECS AI team. The token is sent as a Bearer token to the SAP AI proxy, which forwards requests to the real Anthropic API on your behalf.

🛠 Manual Installation Steps

Step by step
  1. Install Python 3.10 or later Download the Windows installer from python.org.
    During setup: check ✅ Add Python to PATH and ✅ Install for all users (optional).
    Verify from a command prompt: python --version
  2. Install Python packages Open Command Prompt or PowerShell and run: 
    pip install anthropic
pip install python-pptx    (optional — for PowerPoint export)
  3. Create the working directory Create a folder where the app will live, for example: 
    mkdir C:\HANA_Analysis_App
mkdir C:\HANA_Analysis_App\HANA_Analysis_report_generator
mkdir "C:\HANA_Analysis_App\HANA Health Check Reports"
mkdir C:\HANA_Analysis_App\Results
  4. Copy the required files Copy the following files from the source machine / shared location to the new working directory:
    • HANA_HealthCheck_Prompt_Template.md → <WORKING_DIR>\
    • HANA_latest_release.txt → <WORKING_DIR>\
    • SAP_LOGO.png → <WORKING_DIR>\ (optional)
    • hana_analysis_app_v6.01.py → <WORKING_DIR>\HANA_Analysis_report_generator\
  5. Edit the paths in hana_analysis_app_v6.01.py Open the file in Notepad or any text editor and update the constants at lines 35–41 to match the actual paths on the new machine (see the Configuration section for details).
  6. Create the settings.json file Create the folder and file: 
    mkdir %USERPROFILE%\.claude
    Then create the file %USERPROFILE%\.claude\settings.json with your SAP AI proxy token (see the Configuration section for the exact JSON structure).
  7. Verify the SAP AI Proxy is running The app connects to http://localhost:6655/anthropic/ by default. The proxy must be running on the target machine. See the SAP AI Proxy section.
  8. Run the app 
    python "C:\HANA_Analysis_App\HANA_Analysis_report_generator\hana_analysis_app_v6.01.py"
    Or create a shortcut / batch file (see Running the App).

🚀 Automated Installer

Recommended

The file install_hana_analysis_app.bat (included in the same folder as this guide) automates all manual steps. Run it as Administrator on the target machine.

What the installer does

  • Checks Python is installed and accessible on PATH
  • Installs anthropic and python-pptx via pip
  • Prompts you for your working directory path and SAP AI token
  • Creates the full directory structure
  • Copies all required files from the source (script directory)
  • Patches the hardcoded paths in the .py file automatically
  • Writes %USERPROFILE%\.claude\settings.json with your token
  • Creates a desktop shortcut and a run.bat launcher

Usage

REM Right-click → Run as Administrator
install_hana_analysis_app.bat

Follow the prompts. The installer will confirm each step and report any errors before continuing.

Prerequisites for the installer

The installer assumes all source files (.py, .md, .txt, .png) are in the same folder as the .bat file. If running from a network share, copy the entire folder locally first to avoid path issues.

Installer script source

Location: HANA_Analysis_report_generator\install_hana_analysis_app.bat
The script is plain Windows batch — no admin tools, no registry writes (except the desktop shortcut). You can inspect and edit it freely.

▶ Running the App

Usage

Option A — Desktop shortcut (recommended)

The installer creates a shortcut on the desktop. Double-click to launch.

Option B — Batch launcher

Create a file run_hana_app.bat in the working directory:

@echo off
cd /d "C:\HANA_Analysis_App\HANA_Analysis_report_generator"
python hana_analysis_app_v6.01.py
pause

Double-click the .bat to launch. The pause keeps the console window open if there is a startup error.

Option C — Direct command line

python "C:\HANA_Analysis_App\HANA_Analysis_report_generator\hana_analysis_app_v6.01.py"

Generating a report

  1. Click "Browse" and select the HANA Health Check .txt output file.
  2. Verify the file size shown — maximum is 2,500 KB. Files larger than this must be trimmed.
  3. Click "Generate Full Analysis Report". The progress bar shows streaming status.
  4. Wait — generation typically takes 2–5 minutes depending on file size and model response time.
  5. The report opens automatically in Microsoft Edge when complete. It is also saved to the Results\ folder.
  6. Optional: "Export to PowerPoint" button becomes active after a report is generated.

🔗 SAP AI Proxy

Required

The app does not connect to the public Anthropic API directly. It uses the SAP internal AI proxy, which handles authentication and routing to the Anthropic Claude API on behalf of SAP employees.

ParameterDefault valueNotes
Proxy endpoint http://localhost:6655/anthropic/ The proxy runs locally (typically part of Claude Code or a separate SAP AI proxy agent). Verify it is running before starting the app.
Auth token (UUID, personal) Unique per user. Set in settings.json as ANTHROPIC_AUTH_TOKEN. Do not share this token.
Model claude-sonnet-latest Set via ANTHROPIC_MODEL in settings.json. Can be overridden at runtime via the model dropdown in the app.

Verify the proxy is running

Open a browser or run from command line:
curl http://localhost:6655/anthropic/
If you get a response (even an error JSON), the proxy is alive. If the connection is refused, start the SAP AI proxy or Claude Code desktop agent before launching the app.

If your proxy runs on a different port or URL

Update ANTHROPIC_BASE_URL in settings.json to match. The app reads this value at startup — no code change needed.

🔍 Troubleshooting

Help
SymptomLikely causeFix
ModuleNotFoundError: No module named 'anthropic' anthropic not installed pip install anthropic
App opens but "Generate" button is greyed out No file selected, or file exceeds 2,500 KB Select a valid file; reduce file size if needed
Generation Failed: API error 401 Invalid or expired SAP AI token Update ANTHROPIC_AUTH_TOKEN in settings.json
Generation Failed: Connection refused SAP AI proxy not running Start the Claude Code desktop app or SAP AI proxy agent
Report opens but logo is missing SAP_LOGO.png not found in WORKING_DIR Copy the PNG file to the working directory
FileNotFoundError: HANA_HealthCheck_Prompt_Template.md Prompt template missing or WORKING_DIR path wrong Verify the WORKING_DIR constant and that the .md file is present
Edge does not open after generation EDGE_PATH constant points to wrong location Update EDGE_PATH in the .py file to match the Edge installation on the new machine
Response is not valid HTML (first 300 chars shown) Claude returned an error or the model hit the token limit Check the Generation Log in the app; reduce health check file size; try again
Export to PowerPoint — "python-pptx not installed" python-pptx package missing pip install python-pptx
tkinter GUI does not appear / crashes immediately tkinter not bundled with the Python installation Reinstall Python and ensure the tcl/tk optional feature is selected during setup. On a Windows Python installer this is enabled by default.

Getting the Generation Log

The log panel inside the app shows prompt size (in characters and estimated tokens), model used, streaming progress, and any errors. For persistent issues, copy the log content and share it with the tool maintainer (RDE LAC team).
