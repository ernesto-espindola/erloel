📋 Overview

What the app does and who it is for.

The SAP HANA Full Analysis Report Generator is a Windows desktop application that reads a raw HANA Health Check .txt output file and uses the Claude AI (Anthropic SDK) via the SAP AI proxy to produce a comprehensive, professionally styled HTML analysis report — and optionally a PowerPoint presentation.


The app is aimed at SAP ECS / RDE DBAs and engagement leads who perform regular HANA Health Check reviews and need to produce a polished, customer-ready deliverable quickly.


🤖

AI-Powered Analysis

Sends the HANA Health Check data through a structured prompt template to Claude and streams back a full HTML report in real time.

📄

Rich HTML Report

The output is a standalone, self-contained HTML file with SAP branding, section navigation, executive overview, action plan cards, memory/disk gauges, and a glossary.

📊

PowerPoint Export

Extracts 4 key sections from the HTML report into a PowerPoint presentation styled to match the SAP 360 Caretaker Engagement Review template.

🔍

Dynamic Mini-Check Discovery

Automatically detects all mini-check sections present in the health check input and injects them into the prompt — no manual configuration needed.

🌊

Streaming Generation

Uses the Anthropic streaming API. The progress bar and log update token-by-token as the report is built, with live cancel support.

🔒

SAP AI Proxy

Connects to Claude through the SAP internal AI proxy (localhost:6655). Your SAP AI token is read from settings.json — never hard-coded.

📥 Installation

Step-by-step setup using the provided installer.
  1. Verify Python 3.10+ 64-bit is installed Open a command prompt and run python --version. If not installed, download and install the latest 64-bit Python from python.org/downloads, checking "Add Python to PATH".
  2. Ensure all source files are in the HANA_Analysis_report_generator\ folder The installer expects to find hana_analysis_app_v6.02.py in the same folder. The template and release files are looked up in the parent working directory automatically.
  3. Double-click install_hana_analysis_app_v6.02.bat Run as Administrator for best results (required if installing to C:\Program Files or similar protected paths).
  4. Enter the working directory path Press Enter to accept the default C:\HANA_Analysis_App or type a custom path. This is where your Health Check input files and output reports will live.
  5. Enter your SAP AI token Paste your UUID-format SAP AI auth token. If you do not have one yet, leave blank — you can add it to settings.json later. The installer also asks for the proxy URL (default: http://localhost:6655/anthropic/).
  6. Wait for pip installs and file copy The installer installs anthropic (required), python-pptx (optional), and Pillow (optional), then copies all files, patches the path variables, and writes settings.json.
  7. Launch from the Desktop shortcut Double-click "HANA Analysis App v6.02" on the Desktop, or run run_hana_analysis_app_v6.02.bat from the working directory.

Manual installation (no installer)

  1. Install packages: pip install anthropic python-pptx Pillow
  2. Edit lines 37–43 of hana_analysis_app_v6.02.py — set WORKING_DIR and SETTINGS_FILE to your paths
  3. Create %USERPROFILE%\.claude\settings.json (see Configuration section)
  4. Run: python hana_analysis_app_v6.02.py

⚙️ Configuration

The settings.json file that controls AI proxy access.

The app reads %USERPROFILE%\.claude\settings.json at startup. The installer creates this file automatically. Its structure:

{
  "env": {
    "ANTHROPIC_BASE_URL":   "http://localhost:6655/anthropic/",
    "ANTHROPIC_AUTH_TOKEN": "your-sap-ai-token-here",
    "ANTHROPIC_MODEL":      "claude-sonnet-latest"
  }
}
KeyDefaultDescription
ANTHROPIC_BASE_URLhttp://localhost:6655/anthropic/URL of the SAP AI proxy running on your workstation. Change only if your proxy uses a different port.
ANTHROPIC_AUTH_TOKEN(your token)Your SAP AI authentication token in UUID format. Keep this secret.
ANTHROPIC_MODELclaude-sonnet-latestThe Claude model to use. Shown in the app header. Contact the AI team before changing.
⚠️
If settings.json is missing or the token is the placeholder ENTER-YOUR-SAP-AI-TOKEN-HERE, all generation attempts will fail with an authentication error. Replace it with your real SAP AI token.

Hardcoded paths in the .py file (lines 37–43)

The installer patches these automatically. If you move the working directory later, update them manually:

WORKING_DIR   = Path(r"C:\HANA_Analysis_App")
TEMPLATE_FILE = WORKING_DIR / "HANA_HealthCheck_Prompt_Template.md"
RELEASE_FILE  = WORKING_DIR / "HANA_latest_release.txt"
OUTPUT_DIR    = WORKING_DIR / "Results"
LOGO_PATH     = WORKING_DIR / "SAP_LOGO.png"
EDGE_PATH     = r"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe"
SETTINGS_FILE = Path(r"C:\Users\YourUser\.claude\settings.json")

▶️ Using the App

Step-by-step workflow for generating a report.
⚠️
Before you start: ensure the SAP AI proxy is running on localhost:6655. Without it, all generation attempts fail immediately.

  1. Launch the app

    Double-click "HANA Analysis App v6.02" on the Desktop or run run_hana_analysis_app_v6.02.bat. The Tkinter window opens with the SAP-branded header showing the active model.

  2. Browse for the Health Check file

    Click Browse.... The file picker opens in HANA Health Check Reports\. Select the .txt output from the HANA Health Check SQL execution. The file opens in the preview panel (first 60 lines shown). The size badge shows KB and approximate token count.

  3. Verify file size

    The badge turns orange if the file is above 75% of the 2,500 KB limit. If the file exceeds 2,500 KB the Generate button is disabled and a warning appears — trim the input file before proceeding.

  4. Click Generate Full Analysis Report

    The app builds the prompt (template + release info + health check data), detects all mini-check sections, and starts the streaming API call. The progress bar fills as tokens stream in. The log panel shows real-time status messages.

  5. Wait for completion

    Generation typically takes 2–5 minutes depending on file size and model load. A typical report is 40,000–64,000 output tokens. You can click Cancel at any time to abort.

  6. Open in Edge

    Click Open in Edge (green button). The report opens in Microsoft Edge. The HTML file is saved in Results\ with the pattern SID_HANA_Analysis_Report_YYYYMMDD_HHMMSS.html.

  7. (Optional) Export to PowerPoint

    If python-pptx is installed, click Export to PowerPoint (purple button, visible after generation). The PPTX is saved alongside the HTML in Results\.

📏 File Size & Token Limits

Understanding input and output constraints.
LimitValueBehaviour when exceeded
Max input file size2,500 KBGenerate button is disabled; warning dialog appears. Trim the health check file before retrying.
Warning threshold1,875 KB (75%)Size badge turns orange. Generation is still allowed.
Max output tokens64,000 tokensReport may be truncated if Claude reaches the limit mid-section. Reduce prompt complexity or input size.
Expected output tokens~40,000 tokensTypical full report. Generation takes 2–5 minutes at this size.
File preview60 linesThe preview panel shows only the first 60 lines — the full file is still processed.

Tips for large files

  • Remove -- comment header blocks from mini-check output if they are very long
  • Trim redundant repeated rows (e.g. thousands of identical lock wait entries)
  • Split a combined SystemDB + Tenant health check into separate files and generate two reports

🔧 Troubleshooting

Common issues and how to resolve them.

Generation fails immediately with "Authentication error" or 401

⚠️
  • Open %USERPROFILE%\.claude\settings.json and verify ANTHROPIC_AUTH_TOKEN is your real token (not the placeholder)
  • Confirm the SAP AI proxy is running on localhost:6655
  • Try curl http://localhost:6655/anthropic/ in a command prompt — you should get a response (not a connection refused)

App window does not open / tkinter error

⚠️
tkinter is missing from the Python installation. Reinstall Python from python.org ensuring the "tcl/tk and IDLE" optional component is checked. 
python -c "import tkinter; print('OK')"
If this prints an error, tkinter is not available.

ImportError: No module named 'anthropic'

⚠️
Run the installer again, or install manually: 
pip install anthropic
Ensure you are installing into the same Python that runs the script (check where python).

Report generation starts but stops partway / truncated output

ℹ️
  • The input file may be close to the 2,500 KB limit, causing the prompt to exceed the model's context window
  • The output may have hit the 64,000-token limit — check the log for a token count near that threshold
  • The SAP AI proxy may have timed out — restart the proxy and try again

Export to PowerPoint button is not visible

ℹ️
The Export button is currently hidden in the UI (it exists but is not packed). To use PPTX export, run the export function directly in Python or contact the developer to re-enable the button in a future version.

Open in Edge fails / browser does not open

⚠️
The app uses a hardcoded Edge path: 
C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe
If Edge is installed in a different location, edit EDGE_PATH in the .py file (line 42). Alternatively, open the HTML report directly from Results\ in any browser.

SAP logo not showing in app header

ℹ️
Either SAP_LOGO.png is missing from the working directory, or Pillow is not installed. Install Pillow: pip install Pillow, or copy SAP_LOGO.png to WORKING_DIR. The app header will show a warning text in its place — this does not affect report generation.

HANA_HealthCheck_Prompt_Template.md not found

⚠️
The template file must exist at WORKING_DIR / "HANA_HealthCheck_Prompt_Template.md". If it is missing, generation will fail. Copy the template from the source folder or contact the RDE LAC team.
