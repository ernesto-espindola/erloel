📋 Overview

What the installer does.

This installer sets up the SAP HANA Full Analysis Report Generator v6.02 — a Windows desktop application that reads a HANA Health Check .txt output and uses the Claude AI (via SAP AI proxy) to produce a full HTML analysis report, optionally exported as a PowerPoint presentation.


The installer automatically:

  • Verifies Python 3.10+ 64-bit with tkinter
  • Installs anthropic, python-pptx, and Pillow via pip
  • Creates the full working directory structure
  • Copies all required files to the working directory
  • Patches internal path variables in the app to match your system
  • Writes settings.json with your SAP AI proxy token
  • Creates a launcher batch file and desktop shortcut
  • Installs the HTML documentation guides

📂 Step 1 — Extract the ZIP

Always extract before running — never run from inside the ZIP.
  1. Locate the downloaded ZIP in File Explorer

    Find install_hana_analysis_app_v6.02.zip in your Downloads folder.

  2. Right-click → Extract All…

    Choose a destination folder (the suggested subfolder in Downloads is fine). Click Extract.

  3. Confirm all files are present

    The extracted folder should contain at least: install_hana_analysis_app_v6.02.bat, hana_analysis_app_v6.02.py, _patch_paths.py, HANA_HealthCheck_Prompt_Template.md, HANA_latest_release.txt.

⚠️
Do NOT double-click files from inside the ZIP view. Extract first — the installer reads all files from its own folder.

▶️ Step 2 — Run the Installer

How to launch the installer correctly on Windows.
  1. Open the extracted folder in File Explorer

    Navigate to where you extracted the ZIP.

  2. Right-click install_hana_analysis_app_v6.02.bat → Run as administrator

    Recommended to avoid permission errors. If you accept the default install path inside Downloads, admin rights are not required.

  3. Follow the prompts — only 3 inputs required

    The installer needs: (1) working directory path, (2) SAP AI token, (3) proxy URL. Press Enter to accept defaults for all three.

💡
Running from PowerShell? Type .\install_hana_analysis_app_v6.02.bat (with the .\ prefix).
💡
"This app has been blocked"? Right-click the .bat → Properties → check Unblock → OK. Then run again.

🚀 First Use

How to generate your first report after installation.
  1. Ensure the SAP AI proxy is running on localhost:6655

    Without the proxy the app cannot call Claude. Start the proxy before opening the app.

  2. Double-click "HANA Analysis App v6.02" on the Desktop

    A console window opens briefly, then the Tkinter GUI appears with the SAP-branded header and the active model name.

  3. Place your HANA Health Check .txt file in the input folder

    Copy the raw health check output to: HANA Health Check Reports\ inside the working directory.

  4. Click Browse and select the .txt file

    The file picker opens directly in the HC input folder. Select the file — a 60-line preview and file size badge appear.

  5. Click Generate Full Analysis Report

    The progress bar fills as Claude streams the report. Generation takes 2–5 minutes. Click Cancel at any time to abort.

  6. Click Open in Edge when complete

    The report opens in Microsoft Edge. The HTML file is saved in Results\ as SID_HANA_Analysis_Report_YYYYMMDD_HHMMSS.html.

🔧 Troubleshooting

Common installation problems and solutions.

"requires was unexpected at this time" or batch syntax errors

⚠️
Always use the .zip package — extraction preserves CRLF line endings. If running the bare .bat file fails, convert line endings first:

(Get-Content "install_hana_analysis_app_v6.02.bat") | Set-Content "install_hana_analysis_app_v6.02.bat"

"This app has been blocked by your system administrator"

⚠️
Right-click the .bat → Properties → check Unblock at the bottom → OK → run again.

anthropic install fails

⚠️
  • Check internet: ping pypi.org
  • Corporate proxy: pip install anthropic --proxy http://your-proxy:port
  • Behind strict proxy with SSL inspection: pip install anthropic --trusted-host pypi.org --trusted-host files.pythonhosted.org

Paths not patched / WORKING_DIR still points to developer's machine

⚠️
Ensure _patch_paths.py is in the same folder as the installer. If missing from the zip, patch manually — edit lines 37–43 of hana_analysis_app_v6.02.py: 
WORKING_DIR   = Path(r"C:\Users\YourName\Downloads\HANA_Analysis_App")
SETTINGS_FILE = Path(r"C:\Users\YourName\.claude\settings.json")

App opens but "Authentication error" when generating

⚠️
  • Open %USERPROFILE%\.claude\settings.json — verify ANTHROPIC_AUTH_TOKEN is your real token (not the placeholder)
  • Confirm the SAP AI proxy is running: curl http://localhost:6655/anthropic/

Desktop shortcut not created

ℹ️
Run as Administrator, or use run_hana_analysis_app_v6.02.bat directly from the working directory root.

Cannot create directory error

ℹ️
Run as Administrator, or choose a path inside your user profile (e.g. the default Downloads\HANA_Analysis_App).
